# 合同审查工作台

给企业法务和业务负责人用的 AI 合同审查工具。上传或粘贴一份合同，系统会调用扣子工作流把它过一遍：标出有风险的条款并给出可直接落地的修改建议，核验文中引用的法律是否还现行有效，核实合作方企业的工商信息，最后整理成一份飞书报告。你不用逐条抠字眼，先让它扫一遍，再带着重点去细看。

## 它能做什么

- **风险条款审查**：找出付款、违约、知识产权、交付验收、解除终止等常见问题，每条附问题分析和修改建议，按风险等级分类。
- **法律引用核验**：识别合同中引用的法律法规，标出已废止或需要人工复核的条目。
- **企业信息核验**：核实合同相对方的工商登记信息是否一致。
- **飞书报告**：审查完成后自动生成一份完整报告，落到你的飞书云文档里。

## 快速开始

1. 安装依赖（仅首次）：

   ```bash
   npm install
   ```

2. 配置扣子工作流：把根目录的 `.env.example` 复制为 `.env`，填入你的扣子 PAT 和工作流 ID（见下方「扣子工作流配置」）。

3. 启动并打开：

   ```bash
   npm start
   ```

   Windows 上也可以直接双击 `start.bat`。然后浏览器打开 **http://localhost:8787**。

   > 端口默认 `8787`，可通过环境变量 `PORT` 修改。

## 一次完整的使用流程

1. 打开页面，顶部显示「扣子工作流已连接」（未配置密钥则显示「演示模式」）。
2. 选择合同类型、审查立场（甲方 / 乙方 / 中立）、重点审查内容，可补充额外要求。
3. 拖拽或点击上传合同文件（PDF / Word / TXT / MD），也可以直接把合同文本粘进去。
4. 点「开始智能审查」，等待四步进度走完（提取内容 → 查询企业信息 → 审查条款 → 生成报告）。
5. 查看审查意见卡片，按风险等级筛选，复制单条或全部修改建议，点开飞书查看完整报告。
6. 底部有历史记录，方便回看，可一键清空。

## 扣子工作流配置

所有配置都在根目录 `.env` 中（只在服务端读取，不会出现在浏览器）。关键变量：

| 变量 | 说明 |
| --- | --- |
| `COZE_PAT` | 扣子个人访问密钥（PAT）。**只写在 `.env`，不要提交到仓库或写进前端** |
| `COZE_WORKFLOW_ID` | 工作流 ID |
| `COZE_API_BASE` | API 域名：国内 `https://api.coze.cn`，国际 `https://api.coze.com` |

服务端通过 `POST /v1/workflow/run` 调用工作流，参数按固定名字读写：

- **输入**：开始节点需要两个参数 —— `wenjian`（`doc` 类型，合同文件）和 `xuqiu`（`string`，审查立场、重点等需求文本）。
- **输出**：结束节点返回四个字符串 —— `output`（审查意见）、`output1`（法律引用核验）、`output2`（企业信息核验）、`url`（飞书报告地址）。

如果你的工作流参数名和上面不一致，改 `server.js` 里的 `PARAM_NAMES` 和 `normalizeResult()` 即可。

> **关于飞书授权**：工作流里如果用到「飞书云文档」插件，记得把它的授权方式设为**「共享 / 开发者授权」**（而不是「单独 / 运行时授权」）。否则通过 API 调用时会一直返回 `need_auth`，卡在飞书这一步出不来结果。

## 你会拿到什么结果

审查完成后，页面会展示：

- **风险卡片**：每条意见含标题、风险等级、问题分析和修改建议，可单独复制建议。
- **核验摘要**：法律引用核验和企业信息核验的结果。
- **飞书报告按钮**：一键跳转到飞书里的完整审查报告。

> 审查结果由 AI 生成，仅供参考，不构成正式法律意见。

## 演示模式

- 未配置 `COZE_PAT` 时，系统自动返回本地模拟结果，页面会标注「当前为演示结果」。
- 已配置密钥但调用失败时，页面会给出明确错误提示，并支持「重试」或「改用演示结果」。

## 密钥安全

- PAT **仅存于服务端 `.env`**，前端代码、日志、README 均不含密钥。
- `.env` 已加入 `.gitignore`，不会进入代码仓库。
- 前端只能拿到「是否已连接」的布尔状态，拿不到密钥本身。

## 技术说明

- 前端：原生 HTML / CSS / JS，响应式，无框架依赖。
- 后端：Node.js + Express。
- 文件文本提取：`mammoth`（docx）、`pdf-parse`（PDF）；TXT / MD 直接读取；粘贴文本会由 `docx` 转成 Word 再交给工作流。
- 未支持旧版 `.doc` 格式，需先另存为 `.docx`。
